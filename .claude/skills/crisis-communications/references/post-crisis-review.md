# Post-Crisis Review

Hold within one week of the incident closing. Ninety minutes, the full war room, and the client decision-maker. Output goes into `.agents/clients/<client>.md` under Learnings and into the playbook.

## Contents
- Timeline reconstruction
- Five questions
- Scorecard
- Playbook updates
- Client report section

## Timeline Reconstruction

Build from the war-room log, not from memory:

| Time | Event | Our action | Lag | Note |
|---|---|---|---|---|
| | First post appears | | | |
| | First repost by large account | | | |
| | Agency notified | | | |
| | War room opened | | | |
| | Facts confirmed | | | |
| | Holding statement published | | | |
| | Media inquiry received | | | |
| | Resolution statement published | | | |
| | Velocity peaked | | | |
| | Velocity falling 24h | | | |
| | Incident closed | | | |

The lags are the review. Where was the time lost: detection, decision, approval, or drafting?

## Five Questions

1. **Detection:** how long between the first post and the agency knowing? What would have caught it sooner (a monitoring keyword, a creator relationship, a customer-service escalation rule)?
2. **Decision:** was the level called correctly at triage? If it was re-classified, what signal was missed?
3. **Speed:** was the holding statement out within the window for its level? Where did the approval chain stall?
4. **Words:** did any sentence in any statement make it worse, get screenshotted, or need correcting? Why?
5. **Root cause:** what operational failure at the client caused the incident, and is it fixed? A comms review that ignores the root cause schedules the next crisis.

## Playbook Updates

For each finding, one concrete change:

- A new scenario in the risk register with a pre-drafted statement.
- A monitoring keyword added.
- An approver added or a turnaround target changed.
- A sensitive-topic rule added.
- A front-line script updated.
- A content-freeze rule clarified.

Date the playbook version and record who approved the update.

## Client Report Section

In the next monthly report, one page:

- What happened (two sentences).
- Peak reach and duration (measured, with the source).
- What was said and when (links).
- Outcome: sentiment direction at close, customer resolutions completed, media coverage tone.
- Root cause and operational fix.
- Playbook changes made.

No spin. The client remembers how it felt; the report should match.
