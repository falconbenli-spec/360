# Pricing Worksheet

Work through all four parts before quoting. Never quote below the cost floor without cutting scope.

## Part 1: Cost-up floor

List every role that touches the account in a typical month. Hours are estimates; verify against time logs from similar accounts.

|---|---|---|---|
| Account manager | | | |
| Strategist | | | |
| Media buyer | | | |
| Copywriter (AR/EN) | | | |
| Designer | | | |
| Video / motion | | | |
| Analyst / reporting | | | |
| **Total delivery cost** | | | |

Add: tools and subscriptions attributable to the account, plus a general overhead allocation if not already in the loaded rate.

Target margin: the agency sets this once in `.agents/product-marketing.md`. Fee floor = total cost ÷ (1 − target margin).

Setup month usually costs 1.5× to 2.5× a steady-state month (audit, tracking, account restructuring, brand foundations). Price it as a separate setup fee.

## Part 2: Value check

- Client's annual revenue (or target): [verify with client]
- Realistic contribution of this program over 12 months: [range, with the assumption stated]
- Fee as a share of that contribution: [calculate]

If the annual fee is a small fraction of the credible contribution, the price is defensible and can move toward value. If the fee is a large fraction, the scope is too big for the client's size; shrink the scope rather than the margin.

## Part 3: Market sanity

- What has the agency charged for the three most similar scopes? Outcome of each (won/lost, retained how long)?
- What has the client disclosed about current or past agency fees?
- What budget range did the client give for services?

Do not estimate competitor pricing you have not seen.

## Part 4: Tiering

|---|---|---|---|
| Core problem solved | Yes | Yes | Yes |
| Channels | [fewest that work] | [full mix] | [full mix + extra] |
| Content volume | | | |
| Reporting | Monthly | Monthly + dashboard | Weekly + dashboard + QBR |
| Setup fee | | | |
| Monthly fee | | | |
| Minimum term | 3 months | 6 months | 12 months |

Rules:
- The recommended tier is the one the agency believes will reach the objectives. The lean tier must still be honest work, not a trap.
- Price gaps between tiers should be noticeable (roughly 1.5× steps are common) so the choice is clear.
- Every tier states what is excluded.

## Discount trades

A discount is exchanged for something. Pick from:
- Longer minimum term (12 months instead of 6)
- Payment in advance (quarterly or annual)
- Case study and testimonial rights
- Reduced scope (fewer channels, fewer assets)
- Faster decision (valid only until a stated date)

## Media fee reference

For paid media management as a percentage of spend: set a minimum monthly fee that covers the work regardless of spend. Below that spend level, the percentage does not pay for the hours. Above a high spend level, the percentage usually steps down. State the percentage, the floor, and the step-down in the proposal.
